Un « token », c’est quoi ?

Un petit morceau de texte (3 ou 4 lettres). Chaque fois qu’une IA lit ou écrit, un compteur tourne — comme un taxi.

Bonjour,rangezcesfichierspardate,s’ilvousplaît.
0cette petite phrase = environ 22 tokens

En clair : plus l’IA travaille, plus le compteur grimpe. Et il se paie.

Le problème

On fait payer le compteur à l’IA pour des tâches de machine à laver : trier, renommer, convertir, vérifier un format…

0tokens par mois pour UNE étape de 2 000 tokens, exécutée 1 000 fois

En clair : une règle qui ne change jamais n’a pas besoin d’un cerveau. Elle a besoin d’un script.

La règle d’or

Si la règle s’écrit en quelques lignes « si… alors… », c’est du code. Sinon, c’est de l’IA.

⚙ Du CODE

  • Trier, filtrer, renommer
  • Convertir un format, valider
  • Calculer, compter, appeler une API
  • 0 token · millisecondes · même résultat à chaque fois

✦ De l’IA

  • Comprendre un texte libre
  • Rédiger, résumer
  • Arbitrer un cas inédit
  • Là où elle est indispensable

Le libre contre l’outil imposé

Mon point de vue (VTLO). L’intelligence artificielle ne doit pas devenir un péage obligatoire. Quand un raisonnement artificiel commercial s’impose comme passage forcé — son outil, son abonnement, ses règles — on perd la maîtrise de ses propres automatisations.

Je me bats pour que le logiciel libre et le copyleft restent la règle : du code que l’on peut lire, modifier, partager… et qui reste libre pour les suivants.

LireModifierPartagerLe rester (copyleft)

Des scripts locaux, lisibles, sans clé d’API ni abonnement : l’IA devient un choix, pas une obligation. VTLO_REcod3r est publié sous licence GPL-3.0.

Installer en une ligne

Dans votre terminal. Il détecte tout seul le CLI d’IA que vous utilisez.

curl -fsSL https://raw.githubusercontent.com/VTLO/VTLO_REcod3r/main/install.sh | sh

Puis, dans votre CLI : /rec0d → cliquez COD3FORM3 ☺
